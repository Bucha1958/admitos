# AdmitOS

Hospital Management System (SaaS) for Nigerian clinics and hospitals.

**Stack:** React (frontend) · Java / Spring Boot (backend) · MySQL

**Deployment model:** Online-only · Internet required

## Repositories

- **Frontend:** [https://github.com/Bucha1958/admitos-frontend](https://github.com/Bucha1958/admitos-frontend) — React + Vite + TypeScript (separate repo)
- **This repo (`admitos`):** backend (Java/Spring + MySQL) and related server-side work

## Backend

Java / Spring Boot API with MySQL — coming next. Clone this repository for backend development.

## Frontend

The UI lives in a separate repository:

```bash
git clone git@github.com:Bucha1958/admitos-frontend.git
cd admitos-frontend
npm install
npm run dev
```

Open http://localhost:5173
